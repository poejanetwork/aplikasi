Some example scripts for cbparser: A text converter, which is handy if you like bbcode, and want to make some HTML(5), and a simple, yet handy comment script.

Basically it's a guestbook using cbparser for, well, everything. It can be included in another page, or function as a stand-alone script or framework for your own comment/guestbook facility. Have fun!

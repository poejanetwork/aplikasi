    cbparser examples

    Two scripts to demonstrate the cbparser bbcode parser in action..

    text-to-html converter.php

        A simple bbcode-capable bbcode-to-html converter; it outputs the raw
        HTML5 tags back at you, for pasting elsewhere.

    simple-comments.php

        A simple comment script. Basically it's a guestbook using cbparser for,
        well, everything. It can be included in another page, or function as a
        stand-alone script/framework for your own comment/guestbook facility.

        Comments are stored inside "comments.htm", which must be world-writeable
        (chmod 777).

        Feel free to play with the version running at corz.org..

    http://corz.org/machine/source/beta/php/corzblog/examples/simple-comments.php

    For more detailed usage instructions, open either script in a decent text
    editor.
